### Ingesting Agent TRaces with dlthub

This workshop is about tracing agents. It follows the DataTalksClub workshop: https://www.youtube.com/watch?v=A0LmmZf-ggM

Progress: 1 hour and 16 minutes.

You'll learn about:
- How to locate and extract hidden execution traces and raw session logs from local coding assistants.
- How to automatically flatten and normalize heavily nested JSON data strings into clean relational tables.
- How to configure local data pipelines by combining the open-source dlt Python library with DuckDB.
- How to build reactive data visuals and usage charts using modern, interactive Marimo notebooks.
- How to integrate Logfire and Pydantic logging frameworks to monitor production token consumption.
- How to ingest remote log telemetry using custom REST API connectors equipped with automatic pagination rules.
